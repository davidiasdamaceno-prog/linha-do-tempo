# Linha do Tempo

Site para criar, estudar e compartilhar linhas do tempo, com modelos prontos de história, globo com os lugares dos eventos, filtros, quiz e exportação em imagem e PDF.

Acesse: https://davidiasdamaceno-prog.github.io/linha-do-tempo/
